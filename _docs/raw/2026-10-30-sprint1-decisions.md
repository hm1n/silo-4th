# 스프린트1_결정사항 (draft)

이번 스프린트에서 팀이 정해야 하는 것을 모아 둔 문서예요. 내 일이 어떤 결정을 기다리고 있는지, 결정이 나기 전까지 무엇을 할 수 있는지 확인할 때 열어 주세요.

* 결정이 나면 "정한 것" 표로 옮겨요.
* 한 번 정한 내용을 바꿀 때는 기존 줄을 지우지 않고 새 줄을 추가해요.

## 킥오프에서 정할 것

### 1. 학습 범위

정했어요. 학습자는 우리가 미리 준비한 학습셋으로 공부해요. 학습셋이 정해져 있어서 떠올리기 질문과 확인 문제를 미리 만들고 검토할 수 있어요.

학습셋을 바탕으로 아래 두 가지를 PM이 준비해요.

* 개념 목록: 학습셋의 단원에서 개념을 뽑아 목록을 만들어요. 단원 하나에 개념이 여러 개 들어 있으면, 개념마다 어느 단원에 있는지 함께 적어요. 개발자는 이 목록으로 같은 개념을 판단하고, 흐름 3에서 "다시 볼게요"를 누른 학습자를 그 단원으로 보내요.
* 학습셋 파일: 개발자가 왼쪽에 보여 줄 수 있도록 단원별로 나눈 파일을 넘겨요. 어떤 형식으로 받을지는 개발자와 정해요.

학습셋이 왼쪽에 늘 열려 있어서, 학습자가 묻지 않고 학습셋을 다시 읽을 수도 있어요. 그러면 다시 묻는 일이 생각보다 적을 수 있어요. 그래서 학습자가 어떤 단원을 언제 열었는지도 함께 기록해요. 다시 묻지 않고 다시 읽은 경우를 나중에 확인할 수 있어요.

### 2. 학습 화면

정했어요. 학습 화면은 웹으로 직접 만들고, 왼쪽에 학습셋을, 오른쪽에 질문 창을 둬요. 자세한 화면 구성은 "05-화면흐름"에 있어요.

학습 에이전트는 학습자가 질문할 때 왼쪽에 열려 있던 단원의 내용을 알고 답해요. 답하는 방식은 학습자가 평소 쓰는 AI와 같게 해요. 답을 숨기거나 되묻지 않고 바로 답해요. 평소와 달라지는 점이 떠올리기 질문 하나뿐이어야, 결과가 떠올리기 질문 때문인지 알 수 있어요.

### 3. 학습자 조건

* 학습셋의 과목을 최근 2주 안에 AI와 함께 공부한 사람을 8명 모아요. 인터뷰에서 최근 AI 대화 기록을 함께 봐야 하기 때문이에요.
* 학습 에이전트를 매일 쓰라고 요구하지 않아요. 사용을 강제하면 학습자가 떠올리기 질문 때문에 덜 오는지 확인할 수 없어요.
* 대화 기록을 저장하고 분석한다는 내용에 미리 동의를 받아요.

모집이 늦어지면 과목 조건은 그대로 두고, "최근 2주"를 "최근 한 달"로 넓혀요.

### 4. 기기

학습 화면은 왼쪽과 오른쪽으로 나뉘어서 넓은 화면이 필요해요. 그래서 PC 웹을 기준으로 화면을 그리기를 추천해요. 모바일은 이번 스프린트에서 지원하지 않고, 모바일로 들어오면 "PC에서 열어 주세요"라는 안내만 보여 줘요. 학습자를 모을 때 PC로 공부할 수 있는지 함께 확인해요.

### 5. 2주 일정

지금 일정은 1\~14일차로 되어 있어서, 1일차를 월요일로 잡으면 주말에 일해야 하는 날이 생겨요. 평일만 세서 다시 잡기를 추천해요.

| 기간 | 하는 일 |
| -- | -- |
| 1주차 월\~수 | 학습자 인터뷰, 공통 기능 만들기 |
| 1주차 목 | 돕는 방식 정하기 |
| 1주차 목\~금 | 돕는 화면과 기능 만들기 |
| 2주차 월\~금 | 학습자가 학습 에이전트로 공부하기 |
| 3주차 월\~화 | 확인 문제 내기 |

확인 문제는 개념을 마지막으로 본 날부터 3일 넘게 지난 뒤에 내야 해요. 2주차 금요일에 내면 월요일과 화요일에 본 개념만 확인할 수 있어서, 3주차 초에 내요.

## 공통 기능을 만들기 전에 정할 것

### 6. 같은 개념을 판단하는 방법

"LEFT JOIN이 뭐예요?"와 "LEFT JOIN은 언제 써요?"를 같은 개념으로 볼지 정해야 해요.

학습자의 질문마다 AI가 개념 목록에서 개념 하나를 고르게 하기를 추천해요. 이때 질문과 함께, 질문할 때 왼쪽에 열려 있던 단원을 AI에게 알려 줘요. "이 부분이 이해가 안 돼요"처럼 개념 이름이 없는 질문도 어떤 개념에 대한 것인지 고를 수 있어요. 목록이 정해져 있어서, AI가 개념 이름을 새로 지어내는 것보다 결과가 일정해요. 목록에 없는 질문은 "기타"로 두고 세지 않아요. 1주차에는 PM이 결과를 직접 보고 잘못 고른 것을 고쳐요.

### 7. 하루의 기준

"다음 날 보여 준다"와 "서로 다른 날 물었다"를 판단하려면 하루가 언제 시작하는지 정해야 해요. 퇴근 후에 공부하는 학습자는 밤 11시부터 새벽 1시까지 공부하기도 해요. 자정을 기준으로 하면 한 번 앉아서 공부한 것이 이틀로 나뉘어요.

새벽 4시를 하루의 시작으로 보기를 추천해요.

### 8. 학습자 구분

학습자 8명을 2주 동안 구분하려고 로그인 기능을 만들어요. 학습자가 어느 기기에서 들어와도 같은 사람으로 기록되어야, 다시 물은 개념을 빠짐없이 찾을 수 있어요.

구글 로그인처럼 학습자가 비밀번호를 따로 만들지 않아도 되는 방식을 추천해요. 학습자가 가입하다가 그만두는 일을 줄이고, 개발자가 비밀번호 찾기 같은 기능을 만들지 않아도 돼요. 어떤 로그인 방식을 쓸지는 개발자가 정해요.

### 9. 다시 물은 개념을 세기 시작하는 때

둘째 주에만 기록을 모으면, 학습자마다 다시 물은 개념이 몇 개 나오지 않을 수 있어요. 개념이 너무 적으면 보여 주는 쪽과 보여 주지 않는 쪽으로 나눠 비교할 수 없어요.

학습 에이전트가 준비되는 날부터 인터뷰를 마친 학습자에게 쓰게 하기를 추천해요. 1주차에는 기록만 모으고 떠올리기 질문은 보여 주지 않아요. 다시 물은 개념이 2개보다 적은 학습자는 비교에서 빼요.

## 인터뷰를 마친 뒤 정할 것

### 10. 돕는 방식

어떤 방식이 맞는지는 학습자가 같은 개념을 왜 다시 묻는지에 달려 있어요. 방식마다 학습자에게 무엇이 보이는지는 "02-디자이너"에 있어요.

| 학습자가 다시 묻는 이유 | 맞는 방식 |
| -- | -- |
| 답을 읽고 이해했다고 느끼거나, 스스로 떠올려 보지 않아서 | 떠올리기 질문 |
| 같은 것을 다시 물었다는 사실을 몰라서 | 다시 물었다고 알려 주기 |
| 개념이 아니라 문법만 잊어서 | 지난 대화 빠르게 찾기 |

인터뷰 결과가 한쪽으로 모이지 않으면 떠올리기 질문으로 정하기를 추천해요. 세 가지 이유 중 두 가지를 함께 해결할 수 있기 때문이에요.

### 11. 떠올리기 질문과 확인 문제 만들기

AI가 그때그때 떠올리기 질문을 만들게 하면, 질문의 난이도가 들쭉날쭉해서 결과를 비교하기 어려워요.

PM이 개념 목록의 개념마다 떠올리기 질문 1개와 확인 문제 1개를 미리 만들기를 추천해요. 초안은 AI로 만들고 PM이 검토해요. 확인 문제는 떠올리기 질문과 문장을 다르게 써서, 학습자가 답만 외웠는지 구분해요. 디자이너는 이 중 몇 개를 화면 예시 문구로 받아요.

확인 문제는 학습자마다 구글 폼으로 보내고, PM이 미리 정한 채점 기준으로 채점해요.

### 12. 학습자가 다음 날 오지 않을 때

떠올리기 질문은 "다음 날" 보여 주지만, 학습자가 다음 날 오지 않을 수 있어요.

학습자가 다음에 올 때 보여 주고, 실제로 보여 준 날을 기록하기를 추천해요. 알림은 보내지 않아요. 알림을 보내면 학습자가 떠올리기 질문 때문에 덜 오는지 확인하기 어렵고, 만들 것도 늘어나요.

### 13. 학습자의 답을 판단하는 방법

학습자는 떠올리기 질문에 자기 말로 답해서 정답이 하나로 정해지지 않아요.

| 방법 | 좋은 점 | 아쉬운 점 |
| -- | -- | -- |
| AI가 바로 채점하기 | 학습자가 답하자마자 결과를 볼 수 있어요 | 개발자가 만들어야 할 것이 늘어나요 |
| 학습자가 스스로 표시하기 | 지난 답과 비교해 보고 "맞았어요"를 누르면 돼서, 만들 것이 적어요 | 학습자가 실제보다 후하게 표시할 수 있어요 |

학습자가 스스로 표시하는 방법을 추천해요. 이 표시는 화면에 숫자를 보여 줄 때만 써요. 미션에 가까워졌는지는 PM이 낸 확인 문제로 판단하기 때문에, 후하게 표시해도 결과에는 영향이 없어요.

### 14. 잘됐는지 판단하는 기준

이 결정은 측정 기록에 무엇을 저장하는지에만 영향을 줘요. 추천대로 정해지면 "03-개발자"의 측정 기록 표를 그대로 쓰면 돼요.

확인 문제에서 학습자가 아무것도 보지 않고 맞힌 비율로 판단하기를 추천해요. 다시 묻는 횟수는 기준으로 쓰지 않아요. 이 숫자가 줄어도 학습자가 이해해서인지, 공부를 그만둬서인지 알 수 없기 때문이에요.

| 확인할 것 | 기준 | 확인하는 때 |
| -- | -- | -- |
| 다시 묻는 학습자가 있다 | 8명 중 4명 이상 | 인터뷰 |
| 학습자가 떠올리기 질문에 답한다 | 보여 준 질문의 60% 이상 | 둘째 주 동안 |
| 혼자 맞히는 비율이 오른다 | 보여 준 개념이 보여 주지 않은 개념보다 15%p 이상 높다 | 확인 문제 |
| 학습자가 덜 오지 않는다 | 둘째 주 평일 5일 중 평균 3일 이상 학습 에이전트를 연다 | 둘째 주 동안 |

%p는 비율끼리의 차이를 말해요. 예를 들어 40%와 55%는 15%p 차이가 나요. 둘째 주가 시작된 뒤에는 기준을 바꾸지 않아요.

학습자 8명이 개념 몇 개씩으로 비교하기 때문에, 이 결과로 효과를 증명할 수는 없어요. 방향이 맞는지 보고, 스프린트 2에서 더 크게 확인할지 정하는 데 써요.
