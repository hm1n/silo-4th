# 스프린트1_화면플로우 (draft)

학습자가 어떤 화면을 어떤 순서로 거치는지, 상황마다 무엇을 보여 주는지 정한 문서예요. 디자이너는 이 흐름을 바탕으로 화면을 그리고, 개발자는 이 흐름대로 동작을 만들어요.

흐름이 어색하거나 만들기 어려운 곳이 있으면 댓글로 남겨 주세요.

## 누가 무엇을 정하나요

| 사람 | 정하는 것 |
| -- | -- |
| PM | 어떤 화면이 있는지, 화면이 어떤 순서로 이어지는지, 화면마다 보여 줄 정보, 상황별 규칙, 문구 초안 |
| 디자이너 | 화면 배치와 모양, 버튼과 카드의 움직임, 문구 다듬기 |
| 개발자 | 흐름을 동작으로 만드는 방법 |

## 학습 화면 구성

학습자는 대부분의 시간을 학습 화면에서 보내요. 학습 화면은 왼쪽과 오른쪽으로 나뉘어요.

| 영역 | 보여 주는 것 | 학습자가 하는 일 |
| -- | -- | -- |
| 왼쪽: 학습셋 | 우리가 미리 준비한 학습셋. 단원 목록과 지금 보고 있는 단원의 내용 | 단원을 골라 읽으며 공부해요 |
| 오른쪽: 질문 창 | 학습 에이전트와 나눈 대화, 입력창, 혼자 맞힌 개념 숫자 | 왼쪽을 읽다가 궁금한 것을 물어봐요 |

학습자가 질문하면 그때 왼쪽에 열려 있던 단원을 함께 기록해요. 학습 에이전트도 그 단원의 내용을 알고 답해요. 학습자가 "이 부분이 이해가 안 돼요"처럼 물어도 무엇을 묻는지 알 수 있어요.

## 화면 목록

| 화면 | 언제 보이나요 | 보여 줄 정보 |
| -- | -- | -- |
| 로그인 | 학습 에이전트 주소로 처음 들어올 때 | 서비스 이름, 로그인 버튼 |
| 학습 화면 | 로그인한 뒤 항상 | 왼쪽에 학습셋, 오른쪽에 질문 창 |
| 떠올리기 질문 카드 | 오늘 보여 줄 떠올리기 질문이 있을 때 질문 창 맨 위에 | 이 질문이 뜬 이유, 질문, 답 입력창, "다음에 할게요" 버튼 |
| 답 확인 | 학습자가 떠올리기 질문에 답한 뒤 카드 안에서 | 학습자의 답, 지난번 학습 에이전트의 답, "맞았어요"와 "다시 볼게요" 버튼 |

떠올리기 질문 카드와 답 확인은 돕는 방식이 떠올리기 질문으로 정해졌을 때만 만들어요. 다른 방식으로 정해지면 PM이 이 부분을 다시 써요.

## 흐름 1. 처음 들어올 때

1. 학습자가 PM에게 받은 주소로 들어와요.
2. 로그인 화면에서 로그인해요.
3. 학습 화면으로 이동해요. 왼쪽에는 첫 단원이 열려 있어요.
4. 오른쪽 질문 창은 비어 있으니 "읽다가 궁금한 게 생기면 편하게 물어보세요"라는 안내를 보여 줘요.

## 흐름 2. 공부할 때

1. 학습자가 왼쪽에서 단원을 골라 읽어요.
2. 궁금한 게 생기면 오른쪽 질문 창에 물어봐요.
3. 학습 에이전트가 바로 답해요. 답을 숨기거나 되묻지 않아요.
4. 학습자의 질문은 시간, 그때 열려 있던 단원과 함께 기록돼요. 학습자에게는 기록된다는 표시를 따로 보여 주지 않아요.

학습자가 같은 개념을 다시 물어도 화면에는 아무 변화가 없어요. 평소처럼 답해요.

## 흐름 3. 떠올리기 질문을 받을 때

1. 학습자가 다시 물은 개념이 생기면, 다음 날 학습자가 들어왔을 때 질문 창 맨 위에 떠올리기 질문 카드가 떠요.
2. 카드에는 이 질문이 뜬 이유와 질문을 보여 줘요.
3. 학습자가 답을 쓰고 보내면, 카드 안에 지난번 학습 에이전트의 답이 함께 보여요.
4. 학습자는 자기 답과 지난 답을 비교하고 "맞았어요" 또는 "다시 볼게요"를 눌러요.
5. "맞았어요"를 누르면 혼자 맞힌 개념 숫자가 하나 올라가요.
6. "다시 볼게요"를 누르면 왼쪽 학습셋이 그 개념의 단원으로 바뀌어요.
7. 카드가 닫히고 학습자는 평소처럼 공부해요.

학습자가 "다음에 할게요"를 누르면 카드가 닫혀요.

## 상황별 규칙

| 상황 | 보여 줄 것 |
| -- | -- |
| 다시 들어왔어요 | 왼쪽은 마지막에 보던 단원을, 오른쪽은 지난 대화를 그대로 보여 줘요 |
| 오늘 보여 줄 떠올리기 질문이 없어요 | 카드 없이 학습 화면만 보여 줘요 |
| 오늘 보여 줄 떠올리기 질문이 여러 개예요 | 가장 오래 기다린 질문 하나만 보여 줘요. 나머지는 다음 날로 넘겨요 |
| 며칠 만에 들어왔어요 | 위와 같이 하나만 보여 줘요 |
| 오늘 이미 떠올리기 질문을 봤어요 | 다시 들어와도 오늘은 새 카드를 보여 주지 않아요 |
| "다음에 할게요"를 눌렀어요 | 그 개념은 다시 보여 주지 않아요 |
| 답을 쓰다가 화면을 닫았어요 | 다음에 들어올 때 같은 카드를 다시 보여 줘요 |
| 다시 물은 개념이 보여 주지 않는 쪽이에요 | 아무것도 보여 주지 않아요. 학습자는 이 개념이 다시 물은 개념인지 알 수 없어요 |
| 떠올리기 질문 카드가 떠 있는데 왼쪽에 그 개념의 단원이 열려 있어요 | 왼쪽을 다른 단원으로 바꾸지 않아요. 카드에 답하기 전에 답을 볼 수 있다는 점은 받아들여요 |
| 학습 에이전트가 답하지 못했어요 | "답을 가져오지 못했어요. 다시 보내 주세요."를 보여 줘요 |
| 로그인이 안 돼요 | PM 연락처를 보여 줘요 |

하루의 기준은 새벽 4시예요. 학습자에게 알림은 보내지 않아요.

## 문구 초안

디자이너가 화면에 맞게 다듬어 주세요. 뜻이 바뀌면 PM에게 알려 주세요.

| 자리 | 문구 |
| -- | -- |
| 질문 창 첫 안내 | 읽다가 궁금한 게 생기면 편하게 물어보세요 |
| 카드에서 질문이 뜬 이유 | 어제 다시 물어본 LEFT JOIN이에요 |
| 카드의 질문 | LEFT JOIN과 INNER JOIN의 차이를 한 문장으로 설명해 보세요 |
| 넘기기 버튼 | 다음에 할게요 |
| 답 확인 안내 | 지난번 답과 비교해 보세요 |
| 맞았을 때 버튼 | 맞았어요 |
| 틀렸을 때 버튼 | 다시 볼게요 |
| "다시 볼게요"를 누른 뒤 | 괜찮아요. 왼쪽에서 다시 읽어 보세요 |
| 혼자 맞힌 개념 숫자 | 내 힘으로 맞힌 개념 3개 |
