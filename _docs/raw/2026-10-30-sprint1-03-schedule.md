# 03 상세 일정

최종 결과(11/20)까지 누가 언제 무엇을 하는지 정리한 문서예요. 매일 아침 이 문서에서 오늘 할 일과 오늘 끝나야 하는 것을 확인해 주세요. 인터뷰 방법, 학습셋 범위, 발표 범위처럼 "어떻게"에 해당하는 내용은 [진행 가이드](<https://linear.app/silo0/document/03-1-%EC%A7%84%ED%96%89-%EA%B0%80%EC%9D%B4%EB%93%9C-7acec4859ba4>)에 있어요. 작업 하나하나는 리니어 이슈로 관리해요.

## 한눈에 보기

```
10/30 금   11/2 월   11/3 화   11/4 수   11/5 목   11/6 금   11/7-8 주말   11/9 월   11/10 화   ~11/14   11/20
├────────────── 인터뷰 ──────────────┤
├ 착수 ┤├──────── 만들기 ────────┤├─ 열기·안정화 ─┤├─ 학습자만 사용 ─┤├ 준비 ┤├ 발표 ┤├ 계속 사용 ┤├ 최종 ┤
                              기능 동결  학습자에게 공개                  12시 데이터 끊기
```

| 구간 | 날짜 | 목표 |
| -- | -- | -- |
| 착수 | 10/30 (금) | 인터뷰 모집을 시작하고, 만들 준비를 끝내요 |
| 만들기 | 11/2 (월)\~11/4 (수) | 프로토타입을 완성하고 기능을 동결해요. 그동안 인터뷰를 6\~8명 해요 |
| 열기와 안정화 | 11/5 (목)\~11/6 (금) | 학습자에게 주소를 알리고, 주말 동안 문제가 없도록 고쳐요 |
| 학습자만 사용 | 11/7 (토)\~11/8 (일) | 팀은 쉬고, 학습자는 공부하고 확인해요 |
| 발표 | 11/9 (월)\~11/10 (화) | 첫 신호로 발표를 준비하고 발표해요 |
| 계속 사용과 최종 결과 | 11/10 (화)\~11/20 (금) | 시험일까지 데이터를 모으고, 설문까지 합쳐 최종 판단해요 |

## 일정의 전제

| 항목 | 내용 |
| -- | -- |
| 팀 | PO, 디자이너, 개발자 각 1명 |
| 팀이 일하는 날 | 10/30 (금), 11/2 (월)\~11/6 (금), 11/9 (월). 주말은 잡지 않았어요 |
| 학습자가 쓰는 기간 | 발표용은 11/5 (목)\~11/9 (월) 낮 12시, 최종은 11/14 (토) 시험일까지 |
| 대상 | SQLD 제63회(11/14 토)를 준비하며 AI로 공부하는 사람 |

팀이 일하는 날이 평일 5일뿐이라, 만드는 기간을 3일로 줄이고 학습자는 주말을 포함해 쓰게 했어요. 시험 직전이라 확인하고 싶은 동기가 가장 강한 때예요.

## 날짜별 완료 기준

그날이 끝날 때 아래가 끝나 있어야 해요. **굵게** 표시한 날짜는 늦어지면 일정 전체가 밀리는 날이에요.

| 날짜 | 끝나야 하는 것 | 늦어지면 |
| -- | -- | -- |
| **10/30 (금)** | 인터뷰 모집 글이 올라가 있어요. 단원이 정해졌어요. 백로그 티켓이 발행돼 있어요 | 인터뷰와 학습셋 작업이 모두 밀려요 |
| **11/2 (월) 오전** | 기록 구조가 정해졌어요 | PO와 개발자가 동시에 작업할 수 없어요 |
| 11/2 (월) | 첫 화면에서 학습 화면으로 들어가, AI에게 묻고 답을 받을 수 있어요. 질문이 단원, 출처와 함께 저장돼요 |  |
| **11/3 (화)** | 학습 자료와 확인 문제가 서비스에 들어가 있어요. 확신도를 고르고 문제를 풀면 결과가 보여요 | 확인 기능을 테스트할 수 없어요 |
| **11/4 (수)** | 첫 화면부터 내 이해 기록까지 동작하고, 모든 기록이 출처와 함께 남아요. 기능을 동결했어요. 공개 게시글이 준비돼 있어요 | 주말에 버그가 나도 고칠 사람이 없어요 |
| **11/5 (목) 오전** | 기준 숫자가 프로젝트 업데이트에 남아 있어요. 커뮤니티와 지인에게 주소를 알렸어요 | 하루 늦을 때마다 확인 결과가 쌓이는 날이 하루씩 줄어요 |
| 11/6 (금) | 확인 화면이 실제 학습자에게 떴어요. 오류가 나면 PO가 알 수 있어요. 마지막 배포를 마쳤어요 |  |
| **11/9 (월) 낮 12시** | 발표용 데이터를 끊었어요 | 발표 자료를 만들 시간이 없어요 |

## 리스크 대응

| 상황 | 대응 |
| -- | -- |
| 인터뷰 대상이 월요일까지 3명보다 적어요 | 지인의 지인까지 넓혀요. 인터뷰가 적어도 만들기 일정은 그대로 가요 |
| 화요일 저녁까지 확인 문제가 완성되지 않아요 | 단원을 3개로 줄여요 |
| 수요일 저녁까지 확인 기능이 완성되지 않아요 | 내 이해 기록을 빼고 확인 기능에 집중해요 |
| 수요일 저녁까지 내 이해 기록이 완성되지 않아요 | 목요일 오전까지 PO가 마무리해요. 그래도 안 되면 결과 화면에 "지금까지 착각한 개념" 목록만 붙여요 |
| 목요일에 들어오는 사람이 적어요 | 금요일 오전에 다른 커뮤니티에 다시 올리고, 지인에게 주변에 알려 달라고 부탁해요 |
| 목요일에 열지 못해요 | 금요일 오전에 열어요. 확인할 수 있는 날이 하루 줄었다는 점을 발표에 밝혀요 |
| 주말에 오류가 나요 | 월요일 오전에 확인하고, 빠진 기간은 결과 해석에서 빼요 |
