# 0007. 질문 답변 AI 모델은 Claude Sonnet 5.5를 effort low로 쓴다

- 상태: 확정
- 결정 날짜: 2026-11-04
- 결정한 사람: 개발자
- 관련 문서: [질문 답변 AI 모델 조사와 정한 모델](../../raw/2026-11-04-ai-model-selection-research.md), [기술 스택](../tech-stack.md), [개발 규칙](../dev-rules.md), Linear [4-60](https://linear.app/silo0/issue/4-60)

## 상황

`wiki/tech-stack.md`는 11/2까지 같은 질문으로 모델을 비교해 정하고, 11/4 기능 동결 뒤에는 바꾸지 않는다고 적었다. 11/4까지 정하지 못했고, 질문 서버는 `.env.example` 기본값인 Claude Opus 5.5와 effort `low`로 동작하고 있었다. 비교 테스트를 돌릴 시간이 부족해, 개발자는 공식 문서와 비교 자료를 조사한 결과로 정하기로 했다.

질문 기능은 학습자가 읽던 단원 본문을 시스템 프롬프트에 넣고, 질문 하나에 Claude를 한 번 호출해 답을 스트리밍한다. 이전 대화나 도구 호출은 없다. 첫 글자 60초, 전체 240초 제한이 있고, 화면은 10초가 지나면 기다리는 중이라는 문구로 바꾼다. 학습자는 8명이다. (근거: `raw/2026-11-04-ai-model-selection-research.md` "질문 기능의 특성")

## 결정

질문 답변 모델은 Claude Sonnet 5.5 `claude-sonnet-5-5`를 쓰고, effort는 `low`로 둔다. 모델 ID는 코드에 쓰지 않고 `lib/env.ts`의 `env.ANTHROPIC_MODEL`로만 읽는다. 운영 모델은 Vercel 환경 변수로 정한다.

## 검토한 대안

가격은 100만 토큰당 입력과 출력이다. 출처는 Anthropic 공식 문서다.

| 대안 | 장점 | 단점 | 택하지 않은 이유 |
| --- | --- | --- | --- |
| Claude Opus 5.5, effort `low` | 지금 동작하는 설정이라 바꿀 것이 없다. 공식 문서가 대부분의 작업에 처음 권하는 모델이다 | $4, $20으로 Sonnet 5.5의 두 배다. 비공식 측정에서 첫 응답 중앙값이 약 4.5초로 Sonnet 5.5보다 느리다 | 강점인 장시간 에이전트 작업과 복잡한 코딩을 이 기능에서 쓰지 않는다. 비공식 종합 점수도 Sonnet 5.5와 같은 9.0이다 |
| Claude Haiku 5.5 | $0.10, $0.50으로 가장 싸고, 공식 상대 지연이 가장 빠르다 | 공식 설명이 분류, 추출, 라우팅용이다. 안전 분류기가 거절하면 서버 쪽 대체 모델을 쓸 수 없다 | 시험 공부에서 틀린 설명은 피해가 크다. 학습자 8명 규모에서 아끼는 금액은 일주일에 수십 달러 수준이다 |
| 같은 질문으로 세 모델을 비교한 뒤 정하기 | 실제 단원과 질문으로 답 품질과 지연을 확인할 수 있다 | 기능 동결일인 11/4에 비교할 시간이 없다 | 일정 안에 끝낼 수 없다 |

## 결과

- Opus 5.5보다 비용이 절반으로 줄고, 비공식 측정 기준으로 첫 응답이 약 33% 빨라진다. 질문 1,000건 비용은 단원 본문 4,000토큰, 출력 1,000토큰 가정에서 약 $11~18로 추정한다.
- 지금 코드는 `thinking`을 정하지 않고 effort `low`만 넘겨서 Sonnet 5.5에서도 코드를 고치지 않는다. Vercel의 `ANTHROPIC_MODEL` 값만 바꾼다.
- 비교 테스트를 하지 않아, Sonnet 5.5 `low`의 한국어 답 품질은 운영에서 처음 확인한다.
- 안전 분류기가 정상 질문을 거절하면 `error`로 끝난다. 서버 쪽 대체 모델 `fallbacks: "default"`는 넣지 않았다.

## 다시 검토할 조건

- 운영 중 답이 단원 내용과 다르거나 설명이 부족하다는 사례가 쌓이면, effort를 올리거나 Opus 5.5로 바꾸는 것을 검토한다. 기능 동결 뒤에도 환경 변수만 바꾸면 되지만, 바꾸려면 이 ADR을 먼저 고친다.
- Sentry에 거절로 끝난 질문이 반복해서 남으면 `fallbacks: "default"` 도입을 검토한다.
- 학습자가 크게 늘어 비용이 문제가 되면 Haiku 5.5를 다시 본다.
