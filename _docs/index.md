# docs 목차

## 미션

AI와 주고받기만 하는 학습이 아니라, 학습자가 정말 이해했는지 확인하고 그 기록을 남긴다. 학습자가 묻고 확인한 내용을 데이터로 남겨 학습자 개인과 학습 플랫폼이 활용하게 하는 것이 이 프로젝트의 목적이다.

## 폴더 구조

```
_docs/
├── CLAUDE.md   작업 규칙
├── index.md    미션, 폴더 구조, 탐색 순서
├── log.md      작업 기록. 자료 추가와 대체 이력을 남긴다
├── raw/        Linear에 없는 원본 자료의 스냅샷. 저장한 뒤에는 고치지 않는다
├── wiki/       원본을 정리한 지식 문서
│   └── adr/    개발자가 정한 설계 결정 기록
└── output/     발표 자료나 보고서처럼 외부에 공유할 산출물
```

## 탐색 순서

1. [CLAUDE.md](CLAUDE.md)에서 작업 규칙을 확인한다.
2. [log.md](log.md)의 최근 줄에서 어떤 자료가 추가되고 대체됐는지 확인한다.
3. `wiki/`에서 정리된 내용을 찾는다.
4. 근거가 필요할 때만 `raw/`를 연다. 열기 전에 `log.md`에서 대체된 원본인지 확인한다.
5. 최신 결정은 Linear의 현재 스프린트 프로젝트 문서에서 확인한다.
