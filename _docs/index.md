## 프로젝트 한눈에 보기

학습자가 같은 개념을 다시 묻는다는 사실을 학습자도 학습 플랫폼도 확인하지 않고 있다. 이 프로젝트는 다시 물은 개념을 떠올리기 질문으로 돌려주는 학습 에이전트를 만들고, 2주 실험으로 효과를 확인한다.

| 항목 | 내용 | 근거 위치 |
| --- | --- | --- |
| 핵심 지표 | 혼자 떠올려 맞힌 비율 | PRD 3장 |
| 이번 2주에 확인할 가설 | 가설 1(문제), 가설 2(행동), 가설 3(학습) | PRD 4장, 5장 |
| 실험 참여자 | 학습자 8명 | PRD 5장 |
| 판단 기준(제안) | 다시 물은 개념이 있는 사람 4명 이상, 응답률 60% 이상, 두 그룹 차이 15%p 이상 | PRD 5장 |
| 아직 확인하지 못한 것 | 다시 묻는 이유, 비용을 낼 고객, 범용 AI와의 차이, 개인정보 | PRD 7장 |

판단 기준의 숫자는 PRD에서 제안한 값이며, 실험을 시작하기 전에 팀이 함께 확정해야 한다.

### PRD 장별 위치

| 장 | 제목 | 다루는 내용 |
| --- | --- | --- |
| 용어 | 용어 | 다시 물은 개념, 떠올리기 질문, 확인 문제 등 8개 용어를 정의한다 |
| 1장 | 학습자는 같은 개념을 여러 번 물어도 그 사실을 모르고 지나가요 | 가상 인물 지수 씨의 사례로 문제를 설명한다 |
| 2장 | 학습자와 학습 플랫폼 모두 "다시 묻는 질문"을 확인하지 않아요 | 학습자와 학습 플랫폼 양쪽의 문제와 원인 후보 세 가지를 정리한다 |
| 3장 | 다시 물었던 개념을 혼자 떠올려 맞히게 하는 것이 목표예요 | 핵심 지표를 정한 이유, 지표별 계산 방법, 지표의 한계를 설명한다 |
| 4장 | 답을 개선하지 않고, 다시 물은 개념을 떠올리게 해요 | 하는 것과 하지 않는 것, 가설 다섯 가지를 정리한다 |
| 5장 | 2주 동안 가설 1~3을 학습 에이전트로 직접 확인해요 | 인터뷰 질문, 만들 기능 다섯 가지, 역할별 일정, 14일차 판단 기준을 정리한다 |
| 6장 | 시장 규모는 인터뷰에서 두 비율을 확인한 뒤에 계산해요 | 시장 규모 계산식을 제시하며, 두 비율은 아직 비어 있다 |
| 7장 | 아직 확인하지 못한 것이 네 가지 있어요 | 미확인 사항 네 가지를 정리한다 |
